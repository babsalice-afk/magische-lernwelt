# V3 – interaktive Zauberwelt

Dieses Update macht die im Fantasybild gezeichneten Navigations- und Ortsbuttons tatsächlich anklickbar.

## Verhalten
- Die normale obere Web-Navigation wird in der Zauberwelt ausgeblendet, damit keine doppelten Buttons erscheinen.
- Lernen -> Lernbereich
- Zauberwelt -> Karte
- Sammlung -> springt zur Magischen Sammlung
- Gestalten -> springt zum Gestaltungskatalog
- Eltern -> Elternbereich
- Freunde -> vorbereitet, noch nicht freigeschaltet
- Plus/Kristalle -> Eltern-/Belohnungsbereich
- Alle acht Orts-Schilder sind anklickbar und wählen den jeweiligen Bereich.
